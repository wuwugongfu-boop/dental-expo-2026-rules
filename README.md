# 2026 牙材展「百萬回饋大作戰」活動規則網站

會員掃描集點卡、摸彩券上的 QR Code 就會打開這個網站。

## 怎麼修改規則

所有規則文字都在 **`rules.md`** 這一個檔案裡，其他檔案不用動。

1. 在 GitHub 打開 `rules.md`，按右上角的鉛筆圖示（Edit this file）。
2. 直接修改文字。
3. 按右上角綠色的 **Commit changes**，再按一次確認。
4. 約 1 分鐘後網站就會更新，網址不變，QR Code 不用重印。

記得同時把最上方「網站頁首資料」裡的「規則最後更新」改成當天日期。

## 寫法說明

| 想要的效果 | 寫法 |
|---|---|
| 新段落（大標題） | 以 `## ` 開頭，例如 `## 抽獎時程` |
| 段落在上方目錄的名稱 | 標題下一行寫 `目錄：抽獎時程` |
| 段落右上角插圖 | 標題下寫 `插圖：stamp`（可用 hero、alert、chest、crown、getcard、gift、register、stamp、verify） |
| 小標題 | 以 `### ` 開頭 |
| 編號清單 | `1. `、`2. ` 開頭 |
| 項目清單 | `- ` 開頭 |
| 提醒框 | `> ` 開頭 |
| 紅色重點 | 前後加兩個星號：`**15:20**` |
| 表格 | 每列用 `|` 分隔欄位，第一列是表頭，第二列固定寫 `|---|---|` |

不同區塊之間空一行。
